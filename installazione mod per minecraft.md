# passo 0: Controllare di avere java installato

premere il tasto win (tasto in basso a sinistra tra il ctrl e Alt, dovrebbe avere il simbolo ti windows o avere scritto direttamente Win)

digitare cmd e selezionare il "prompt dei comandi" e premere invio
<img width="767" height="669" alt="Pasted image 20251109011108" src="https://github.com/user-attachments/assets/6ae3818b-1f8b-4436-bfa9-aaed3da6bcf3" />


all'interno del prompt scrivere "java --version" e controllare l'output.
se non è come quello riportato nell'immagine sottostante (java x.x.x) bisogna scaricare java
<img width="1112" height="622" alt="Pasted image 20251109011314" src="https://github.com/user-attachments/assets/0712d90c-175a-4cb6-ad2d-4f67f7acda47" />


# passo 0.1: installare java
andare al link https://www.oracle.com/java/technologies/downloads/#jdk21-windows e, nella sezione "windows" installare il file x64 MSI installer cliccando il link (evidenziato nella foto sottostante)

<img width="1845" height="712" alt="Screenshot 2025-11-10 081850" src="https://github.com/user-attachments/assets/3efd7bea-bc55-4903-9815-17de380eebda" />

fare doppio click sul file installato. dare gli accessi e procedere all'installazione. apparirà una finestra come questa: 
<img width="490" height="378" alt="Pasted image 20251109011909" src="https://github.com/user-attachments/assets/6d544c4b-b676-46c2-82a5-753f17a538c2" />

significa che siete pronti all'installazione, cliccare next. scegliere il percorso di installazione (va bene lasciare quello di default) e cliccare nuovamente next. dare i permessi e infine cliccare chiudi alla fine dell'installazione
